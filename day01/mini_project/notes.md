# Day 1 Notes

## Terminal Commands
1. `pwd` - Shows the absolute path to the current directory you are in.
2. `ls -la` - Lists all files and folders in the current directory, including hidden ones, with detailed information.
3. `cd ~` - Changes your current directory to your home directory.
4. `mkdir` - Creates a new directory with the specified name.
5. `rm` - Removes a file permanently (use with caution as there is no recycle bin).

## Git Commands
1. `git init` - Initializes a new Git repository in the current directory, allowing Git to start tracking changes.
2. `git status` - Shows the current state of the working directory and staging area, indicating which files are modified, staged, or untracked.
3. `git commit -m "message"` - Takes a snapshot of the staged changes and saves it permanently in the repository's history with a descriptive message.
